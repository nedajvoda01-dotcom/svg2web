# meta.json

Файл содержит метаданные о парсинге SVG: информацию об исходном файле, времени обработке, размерах холста и семантическом контексте (title/description). Используется для версионирования, кэширования и контекстной генерации кода.

## Структура

```json
{
  "source": "Frame 1.svg",
  "parsed_at": "2024-01-15T10:30:00Z",
  "canvas": {
    "width": 1922,
    "height": 950
  },
  "viewBox": [0, 0, 1922, 950],
  "title": "Dashboard Design",
  "description": "Main dashboard layout"
}
```

## Поля

### `source`
- **Тип**: `string`
- **Описание**: Имя исходного SVG-файла (только имя файла, без пути). Используется для трассировки происхождения данных и формирования имен выходных файлов при генерации.

### `parsed_at`
- **Тип**: `string` (ISO 8601)
- **Описание**: Временная метка обработки SVG в формате ISO 8601 с UTC (оканчивается на `Z`). Используется для инвалидации кэша и отслеживания версий артефактов.

### `canvas`
- **Тип**: `object`
- **Описание**: Физические размеры холста SVG в пикселях.

**Canvas Object:**
- `width`: number — ширина холста (обычно соответствует width атрибуту SVG или viewBox[2])
- `height`: number — высота холста (обычно соответствует height атрибуту SVG или viewBox[3])

### `viewBox`
- **Тип**: `[number, number, number, number]`
- **Описание**: ViewBox SVG как массив из четырех чисел `[min-x, min-y, width, height]`. Определяет координатное пространство и масштабирование. Критично для адаптивной верстки и корректного отображения на разных размерах экрана.

### `title`
- **Тип**: `string | null`
- **Описание**: Заголовок/название дизайна, извлеченное из:
  - `<title>` элемента SVG
  - Атрибута `aria-label` на корневом элементе
  - Имени слоя в Figma (если экспортировано с метаданными)
  
  Может быть `null` если заголовок не обнаружен.

### `description`
- **Тип**: `string | null`
- **Описание**: Описание макета, извлеченное из:
  - `<desc>` элемента SVG
  - Комментариев в SVG
  - Метаданных Figma/Illustrator
  
  Используется для генерации meta-тегов в HTML и документации компонентов.

## Примечания

- **Версионирование**: Поле `parsed_at` вместе с версией генератора (из `Cargo.toml`) используется для проверки актуальности кэша. Если `parsed_at` или версия генератора изменились — кэш инвалидируется.
- **Консистентность размеров**: Обычно `canvas.width === viewBox[2]` и `canvas.height === viewBox[3]`, но это не всегда так (например, если SVG имеет фиксированный размер, отличный от viewBox). Генератор использует `canvas` для расчета физических размеров компонентов, а `viewBox` — для масштабирования SVG-элементов.
- **Title в генерации**: Если `title` присутствует, генератор использует его для:
  - `<title>` тега в HTML
  - Имени компонента (конвертация в PascalCase: "Dashboard Design" → `DashboardDesign`)
  - Имени директории выхода (slug: "dashboard-design")
- **Timezone**: Всегда хранится в UTC (суффикс `Z`) для избежания проблем с часовыми поясами в CI/CD и распределенных командах.
