# Serialization

## serde и производительность

- Сериализация выполняется через serde.
- Для снижения аллокаций используется zero-copy там, где возможно (Cow).
- Для больших файлов (10MB+) поддерживается streaming-подход, чтобы не держать все в памяти сразу.

## Форматы вывода

- Единый JSON: самый простой путь для большинства сценариев.
- Split-output (6 файлов): используется при --split-output для partial read и инкрементной обработки.

## Версионирование

- В meta хранится поле version (semver).
- Для старых форматов предусмотрены transform-функции миграции в актуальную модель.

## Сжатие

- zstd: применяется для disk cache (баланс скорости и compression ratio).
- gzip: применяется для передачи данных через сетевые/wasm границы.
