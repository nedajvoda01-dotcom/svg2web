# Extraction

## Base64 изображения

- Декодирование URI вида data:image/png;base64,...
- Определение формата по magic bytes.
- Конвертация в WebP с целевым quality 85%.
- Генерация 1x и 2x вариантов для Retina-экранов.

## Шрифты

- Парсинг font-family через CSS parser.
- Определение weight/style (normal, bold, italic и др.).
- Разрешение шрифтов через Google Fonts API с кэшированием ответов.
- Fallback на system font stack при недоступности внешнего источника.

## Внешние ресурсы

- Загрузка через async HTTP клиент (reqwest).
- Таймаут 30s.
- Retry: до 3 попыток с exponential backoff.
- Кэш загрузок в памяти процесса (без записи на диск в этом слое).

## Ошибки

- Недоступный URL (404/500): ресурс помечается как failed и передается в отчет.
- Невалидное изображение (corrupt base64): запись ошибки с указанием узла.
- CORS при загрузке шрифтов/ресурсов: в web-среде возвращается явная ошибка с рекомендацией inline/fallback.
