# Parsing

## usvg как основной парсер

- usvg используется как основной движок с широкой поддержкой SVG spec.
- После разбора выполняется нормализация: структура приводится к упрощенной модели core.
- Ограничение: вход должен быть валидным SVG.

## Fallback

Если usvg не может разобрать документ, используется fallback на roxmltree для базовых элементов и восстановления минимально рабочего дерева.

## Обработка SVG-фич

- Базовые формы (rect, circle, path): конвертация к path data.
- Группы (g): flattening c учетом transforms.
- Текст: раскрытие в path или сохранение текста с font metadata (в зависимости от режима).
- Градиенты и паттерны: нормализация в solid colors или сохранение как gradient assets.
- Маски и clip-path: применение к итоговой геометрии перед сериализацией.

## Валидация

- Well-formed XML проверяется через quick-xml.
- Проверяется наличие xmlns.
- Разрешаются циклические ссылки (use -> def) с защитой от бесконечной рекурсии.

## Ошибки

- SvgParse: ошибка парсинга с указанием строки/позиции.
- InvalidSvg: структурные проблемы документа (некорректные ссылки, несовместимые узлы).
