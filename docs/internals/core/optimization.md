# Optimization

## simplify_paths

Используется для уменьшения количества точек без заметной потери визуального качества.

Ключевые шаги:

- Douglas-Peucker для редукции полилиний.
- Конвертация коротких кривых Безье в линии, когда ошибка ниже tolerance.
- Удаление коллинеарных точек.

Псевдокод:

```text
function simplify(points, tolerance):
  keep first and last
  find point with max distance to segment(first, last)
  if max_distance > tolerance:
    recurse(left_part)
    recurse(right_part)
  else:
    remove middle points
```

Влияние tolerance:

- меньше значение: выше точность, меньше сжатие;
- больше значение: сильнее сжатие, выше риск визуальных отклонений.

## deduplication

Используется для удаления повторяющихся структур.

- Хеширование поддеревьев (SHA256 по нормализованной структуре).
- При совпадении хеша запускается проверка structural similarity > 95%.
- Для совпавших блоков объединяются стили и ссылки на общие элементы.

Параметр threshold задает порог структурной похожести при разрешении коллизий.

## minification

- Генерация коротких id: a, b, c... вместо длинных uuid.
- Удаление дефолтных атрибутов (например, fill="#000", если это значение по умолчанию).
- Удаление комментариев и metadata.

## Трейдоффы

- precision vs размер файла: меньшая precision уменьшает размер, но может ухудшать точность геометрии.
- время оптимизации vs время генерации: агрессивная оптимизация удлиняет preprocessing, но упрощает downstream-генерацию.
