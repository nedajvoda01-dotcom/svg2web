# Web интерфейс

## Доступ

- Публичный URL: https://svg2web.vercel.app
- Локальный запуск:

```bash
cd web
npm install
npm run dev -- --port 3000
```

После запуска откройте http://localhost:3000.

## Функции интерфейса

### Drag and drop

- Поддерживаемые форматы: .svg и .zip.
- Можно перетаскивать файл в drop-зону или выбрать через диалог.

### Preview

- Зум колесиком мыши.
- Сетка (toggle on/off).
- Rulers для визуального контроля размеров и отступов.

### Анализ

Панели:

- Structure: дерево SVG-элементов.
- Metrics: сложность, размер, число узлов/путей.

### Экспорт

- Формат через radio buttons: React, Vue, Vanilla.
- Download ZIP.
- Copy-to-clipboard для кода.

## Ограничения

- Размер файла: до 50MB. При превышении показывается ошибка: "WASM размер ограничен: загрузите файл меньше 50MB".
- Нет прямого доступа к файловой системе (нельзя сохранить в произвольную папку напрямую).
- CORS: внешние ресурсы (например, шрифты по URL) могут не загрузиться. В интерфейсе показывается предупреждение: "Внешний ресурс недоступен из-за CORS".
- Поддерживаемые браузеры: последние 2 версии Chrome/Edge/Firefox/Safari.
- IE11 не поддерживается.

## Privacy

- Обработка происходит локально в браузере, данные не отправляются на сервер.
- Кэш хранится в LocalStorage.
- Очистка кэша: DevTools -> Application -> Local Storage -> Clear.

## Отладка

- Проверяйте ошибки WASM в DevTools Console.
- Кнопка Report Bug отправляет stack trace для диагностики.
